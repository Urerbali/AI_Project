# AI Recommendation System

Este proyecto implementa un sistema de recomendación básico en Python utilizando la librería scikit-learn y el algoritmo K-Nearest Neighbors (KNN).

## Descripción del Proyecto
El script recommendation_system.py entrena un modelo clasificador utilizando un conjunto de datos simulado de productos con características como precio, calificación y popularidad. El sistema permite recomendar artículos similares según las características ingresadas.

## Tecnologías Utilizadas
- Python 3
- scikit-learn
- pandas
- GitHub Copilot

## Estructura del Repositorio
- recommendation_system.py: Script principal con el modelo de IA y la función de recomendación.
- README.md: Documentación general del proyecto.
